# dsh-corner-studio

一条滑杆统管全界面圆角，一条滑杆调节圆角平滑度，界面字体与代码字体可分别更换。

## 功能

| | 说明 | 默认 |
|---|---|---|
| **圆角大小** | 一条滑杆（0–24px）按宿主原生比例同步缩放全部六档圆角 | 12px = DSH 原生 |
| **圆角平滑** | 超椭圆连续曲率，即 iOS 图标那种圆角 | 1.5 = DSH 原生 |
| **字体更换** | 界面字体与代码字体独立设置，另有字重选择 | 系统默认，不改动 |

## 使用

**设置 → 通用 → 圆角与字体**。

### 圆角大小

| 取值 | 效果 |
|---|---|
| 0 | 全直角 |
| 12 | DSH 原生圆角（默认） |
| 24 | 明显圆润 |

### 圆角平滑

| 取值 | 效果 |
|---|---|
| 1.0 | 普通圆弧 |
| 1.5 | DSH 原生（默认） |
| 2.0 | 接近苹果 squircle |
| 3.0 | 接近方正 |

依赖内核的 `corner-shape` 能力（Chromium 139+）；不支持时该滑杆自动禁用并提示。

### 字体

界面字体与代码字体各有三种换法：

1. **预设** — 按「中文黑体 / 中文宋楷 / 英文无衬线 / 英文衬线 / 等宽」分组，共 80+ 项
2. **手动输入** — 填电脑里已安装的字体名，留空表示不改动
3. **上传文件** — `.ttf` / `.otf` / `.woff` / `.woff2`，存在本机浏览器，不联网

另有 **字体粗细** 滑杆（300–700，默认 400）：提升正文的字重，标题与已加粗部分保持原样，层次不会被压平。还有 **字体平滑** 开关，开启抗锯齿与排版优化——注意 Windows 的字体渲染由系统 ClearType 控制，浏览器会忽略抗锯齿开关，因此那里主要生效的是排版优化。每项都有即时预览。

## 安装

把插件放入 DSH profile 的 `node_modules`，并在该 profile 的 `package.json` 中把 `dsh-corner-studio` 加入 `dependencies` 与 `dsh.profile.bundles`；重启桌面端生效。仓库内的 `rollback.ps1` 可一键回滚。

## 常见问题

- **改了没反应** — 确认总开关已打开；新装的插件需要重启桌面端。
- **平滑滑杆是灰的** — 当前内核不支持 `corner-shape`。
- **换了字体没变化** — 字体名拼错，或系统未安装该字体（未安装的请用「上传文件」）。
- **想全部还原** — 设置行底部的「恢复全部默认」。
